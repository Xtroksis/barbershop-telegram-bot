# Barbershop Bot — демо Telegram-бота для записи клиентов

Демо-бот на Python (pyTelegramBotAPI): клиент записывается на услугу в несколько нажатий, а владелец сразу получает уведомление.

Попробовать: @barbsshop1_bot

## Возможности

- выбор услуги, дня и свободного времени через inline-кнопки
- занятые слоты автоматически скрываются
- запись сохраняется в JSON-файл
- клиент видит свои записи и может отменить запись
- владелец получает уведомление о каждой новой записи и отмене
- прайс и контакты

## Запуск

1. `pip install pyTelegramBotAPI`
2. Скопируй `config.example.py` в `config.py` и вставь токен от @BotFather и свой Telegram ID
3. `python bot.py`

## Что можно доработать под ваш бизнес

- свои услуги, цены, график работы и количество мастеров
- напоминания клиентам за час до визита
- рассылки и акции
- админ-панель с расписанием на день
- подключение оплаты и базы данных
